# PJLink ↔ HTTP мост

HTTP-сервер, который принимает REST-подобные запросы и транслирует их в PJLink-команды проекторам по TCP (порт 4352). Удобен для интеграции проекторов в веб-панели, скрипты и системы автоматизации.

## Возможности

- Единый HTTP-интерфейс для управления несколькими проекторами.
- Команды: узнать состояние, включить, выключить.
- Многопоточная обработка запросов (keep-alive, HTTP/1.1).
- Подробное логирование: таймауты подключения/чтения, приветствие PJLink, сырые ответы.
- CORS включён (`Access-Control-Allow-Origin: *`) — можно дёргать из браузера.

## Требования

- Python 3.7+
- Сетевой доступ к проекторам по TCP-порту **4352** (PJLink).
- Проекторы должны работать **без пароля** (приветствие `PJLINK 0`). Режим `PJLINK 1` не поддерживается.

## Запуск

```bash
python pjlink_server.py
HTTP-сервер слушает 0.0.0.0:9001 (порт задаётся константой HTTP_PORT).

Настройка
В начале файла:

Константа	По умолчанию	Назначение
HTTP_PORT	9001	Порт HTTP-сервера
PROJECTOR_PORT	4352	Порт PJLink на проекторах
CONNECT_TIMEOUT	3	Таймаут подключения, сек
READ_TIMEOUT	3	Таймаут чтения ответа, сек
PROJECTORS	словарь	Имя → IP-адрес проектора
Список проекторов задаётся в словаре PROJECTORS:

python
PROJECTORS = {
    "pro21": "192.168.12.21",
    "pro51": "192.168.12.51",
    ...
}
HTTP API
Базовый URL: http://<host>:9001

GET /status
Проверка работоспособности сервиса.

json
{
  "ok": true,
  "service": "PJLink bridge",
  "projectors": ["pro21", "pro51", "pro61", "pro62"]
}
GET /list
Список проекторов и их IP.

json
{
  "ok": true,
  "projectors": {
    "pro21": "192.168.12.21",
    "pro51": "192.168.12.51"
  }
}
GET /<projector>/state
Запросить состояние питания (%1POWR ?).

json
{
  "ok": true,
  "projector": "pro21",
  "ip": "192.168.12.21",
  "action": "state",
  "raw_response": "%1POWR=1",
  "error": null,
  "power": "on"
}
Возможные значения power: off, on, cooling, warmup, unknown(...).

GET /<projector>/on
Включить проектор (%1POWR 1).

GET /<projector>/off
Выключить проектор (%1POWR 0).

Коды ответов
Код	Когда
200	Команда успешно выполнена
404	Неизвестный путь / проектор / действие
502	Ошибка связи с проектором (таймаут, отказ, авторизация и т.п.)
500	Внутренняя ошибка обработчика
При ошибке в теле ответа будет "ok": false и поле error с описанием.

Примеры
bash
# Состояние
curl http://localhost:9001/pro21/state

# Включить
curl http://localhost:9001/pro21/on

# Выключить
curl http://localhost:9001/pro51/off

# Список проекторов
curl http://localhost:9001/list
Логирование
Уровень INFO. В лог попадают:

установка соединения и таймауты;

приветствие проектора и тип авторизации;

отправленная команда и сырой ответ;

ошибки HTTP-обработки.

Пример:

text
12:00:01 [INFO   ] [Thread-2] [192.168.12.21] '%1POWR ?' → '%1POWR=1' (0.04s)
Ограничения
Не поддерживается PJLink-аутентификация (PJLINK 1).

Нет встроенной аутентификации HTTP — не выставляйте сервис в открытый интернет без прокси/фаервола.

Нет кэширования — каждый запрос открывает новое TCP-соединение к проектору.
